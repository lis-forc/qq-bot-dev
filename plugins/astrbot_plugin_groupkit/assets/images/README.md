# 图片素材

这个插件的图**由你来提供**。代码不画图，只负责找到图、挑一张、把字排上去。
所以「放哪儿、叫什么名字」就是唯一的接口，下面是死约定。

```
assets/images/
├── checkin/    签到运势图    发「签到」时按种子抽一张，和文字一起发出去
├── catalog/    表情图鉴      发「表情列表」时按文件名顺序发出去
└── cards/      个人名片      信息卡拿它当底图往上排字
```

## 三条命名规则

**1. 排序按「自然序」，数字不会排错**

`2.png` 会排在 `10.png` 前面（不是按字母那样把 10 排到 2 前面）。
所以封面、玩法、细节按顺序编号就能顺序发出去：

```
catalog/01-封面.png  catalog/02-玩法.png  catalog/03-细节.png
```

**2. `cards/` 里，文件名去掉扩展名就是名片名**

`男` / `女` 是**保留名**，不是商品：

```
cards/男.png          基础名片，男群友自动用，免费、不上架
cards/女.png          基础名片，女群友自动用
cards/樱花.png        商品，按全局价卖（card_skin_price，默认 50）
cards/夜空@120.png    商品，单独定价 120
cards/星轨=200.png    同上，写成 = 也认
```

- 群友的性别没填就按**男**处理（QQ 里没写性别、或者资料是 unknown，都算没填）。
  主动发「性别 保密」的人也会用男版底图 —— 只有两张底图，没有第三张。
- 买的名片优先于基础名片；买的那张被删了会自动退回基础名片，不会报错。
- 价格只有一个来源：**文件名里的 `@价格`**。没写就用 `card_skin_price`。
  没有第二种定价入口，改价就是改文件名。

**3. 只认这些扩展名**

`png` `jpg` `jpeg` `webp` `gif` `bmp`。丢 `.psd` `.xcf` 进来不会被误认成图片。
名片建议用 **png**：jpg 在浅色底上会有压缩噪点，排上去的字边缘会发毛。

## 名片底图的构图

信息卡是 **1280×720**，字只排在**左边**，所以底图右侧放人像、左侧留白：

```
┌─────────────────────────┬──────────────────┐
│  MEMBER CARD            │                  │
│  姓名（最大）            │                  │
│  性别 · 称号             │      人像         │
│  ─────────────          │                  │
│  爱好 / 额度 / 抽奖次数   │                  │
│  在册天数        名片款式 │                  │
└─────────────────────────┴──────────────────┘
   ← 约 600px 可以排字 →      ← 别放重要细节 →
```

- 左边 600px 内不要放人像主体或关键细节，字会盖上去。
- 就算底图左边不白也能用：渲染时会在左侧铺一层由白到透明的渐变幕，
  深色字照样读得清，只是画面会柔一点。
- 尺寸不是 1280×720 也行，会自动 cover 裁切（不拉伸，人像不会变形）。

## 现在里面有什么

- `checkin/` 三张猫图（贪吃不胖 / 逢考必过 / 人见人爱），都是「符咒祝福」的调子，
  和运势正好搭。同一天同一个人永远抽到同一张，重发「签到」不会换图。
- `catalog/` 一张 `01-表情模板目录.png`（1610×5543 的长图，6 列 300 个模板）。
  发「表情列表」直接把这张发出去；发「表情列表 2」只会发第二张（现在只有一张，
  页码越界会夹到最后一张）。
- `cards/` 两张基础名片 `男.png` / `女.png`（1280×720）。商店里还没有商品图，
  所以「商店」暂时只卖双倍卡和抽奖券。

## 目录空了会怎样

| 目录 | 空了的表现 |
|---|---|
| `checkin/` | 签到只发文字，不附图（功能不受影响） |
| `catalog/` | 「表情列表」退回文字清单，按 `meme_catalog_size` 分页列模板名 |
| `cards/` | 信息卡用程序画的浅色渐变底，字照样排得出来 |

## 换图不用重启

扫描目录时靠目录 mtime 判断有没有增删，所以**运行中丢一张图进去立刻生效**。
想指向别的目录（比如服务器上的共享盘），改配置项 `image_root`，填绝对路径即可。
